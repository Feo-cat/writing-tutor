# 目录说明与迁移记录

本项目是 Web 写作助手的独立副本。Git 历史从整理后的文件重新开始，不继承旧仓库提交、分支、标签或远端配置。

## 文件大致做什么

| 文件或目录 | 简单解释 |
|---|---|
| `web/src/App.tsx` | 网页主要界面：选题、提纲、问答和成稿 |
| `web/src/api.ts` | 网页与 Python 后台之间的通信 |
| `web/src/index.css`、`main.tsx` | 页面外观及启动入口 |
| `web/public/`、`web/index.html` | 页面使用的图片、图标及 HTML 外壳 |
| `web/package*.json` | 前端需要安装的工具与固定版本 |
| `web/tsconfig*.json`、`vite.config.ts`、`eslint.config.js` | 前端类型检查、构建、开发代理及代码检查设置 |
| `server.py` | 后台接收网页操作，推进写作流程，把进度和结果发回页面 |
| `writing_assistant.py` | 真正执行研究、策划、教学、编辑和终审的核心代码 |
| `makingof.py` | 项目复盘用的访谈提示词，以及提纲缓存和已完成内容识别；从旧模块中提取，取消独立启动入口 |
| `fact_checker.py` | 可选事实核查工具：拆分陈述、检索证据、判断依据 |
| `run_eval.py`、`eval_schema.py` | 开发时检查核查工具的效果与评测数据格式 |
| `eval_cases.sample.json` | 12 条公开示例题，只用于检查数据格式和流程 |
| `eval_manifest.json` | 样例校验值与历史完整题库的数量说明；不含完整题目或结果 |
| `_test_hardening.py`、`_test_hardening_fc.py`、`_test_eval.py` | 写作、网页、核查与评测工具的回归检查 |
| `_stubs/`、`_stubs_fallback/` | 测试用的“假模型、假搜索、假框架”，避免测试调用真实服务 |
| `pyproject.toml`、`uv.lock`、`requirements.txt`、`.python-version` | Python 项目信息、依赖与版本；以 uv 锁文件安装为准 |
| `.env.example` | 空白配置样板，复制后填写使用者自己的信息 |
| `.gitignore`、`.gitattributes` | 防止提交私人产物，统一文本换行，保持评测指纹一致 |
| `run.sh` | 已有的 Bash 前后端开发入口，跨平台整理待后续完成 |
| `.github/workflows/tests.yml` | 未来推送后可执行的替身回归检查；本阶段尚未在新仓运行 |
| `README.md`、`AGENTS.md`、`docs/` | 使用说明、开发约定、迁移与评测记录，以及假数据截图 |

## 本次整理

- 按明确文件清单复制，没有复制旧 `.git`、私有配置、草稿、素材、完整题库及原始结果。
- 不迁入独立写作命令行入口、MCP 服务、雷达、学习实验、个人计划及相应自动任务；旧项目中的原文件保留。
- 将 Web 需要的复盘共用模块命名为 `makingof.py`，同步后台和回归检查的引用。内部测试需要的适配器继续保留。
- 移除固定作者画像，策划和导师改为依据使用者提供的背景及回答判断，不默认绑定编程语言、职业或经验。
- 网关账本只在显式配置路径时读取，取消自动查找相邻个人项目。复盘草稿使用通用默认名称。
- 清理代码中的私人复盘叙述、绝对路径和旧产品说明；保留必要技术约束和方法解释。
- 删除未使用的前端模板资源，保留实际页面图片及明确标注为假数据的截图。
- 移除已无保留模块使用的 Anthropic SDK 及其专用依赖 `docstring-parser`，同步锁文件和依赖镜像；其余依赖版本保持原值。
- 重写配置样例和使用说明，保留公开的冻结评测样例，单独说明历史元数据的含义。
