# 写作助手 · writing-tutor

先学懂，再用自己的话写作。输入选题后，研究员检索素材，策划安排提纲，导师逐节先讲再问，编辑把作者的回答整理成初稿，终审提出修改建议。终审不会替作者改写正文。

代码已整理为 Web 项目。基础版本已通过 GitHub 自动检查，以及 Mac 上的依赖安装、回归检查、前端构建和无配置首页展示；真实模型写作流程仍需在运行机验收。

## 功能范围

- Web 写作：选题、确认或修改提纲、逐节问答、生成和下载初稿、查看本地作品档案。
- 学习模式通过 ddgs 检索资料；项目复盘模式读取使用者自己的素材，采访实际经历。
- 所有写作均使用真实模型。未配置服务时可以打开网页查看配置提示和已有作品，开始写作会被阻止。
- 不提供假数据模式、独立 MCP 服务或论文雷达；内部兼容函数和测试工具继续保留。
- 可选事实核查和评测开发工具仍在，暂未加入 Web 核查页面。

这是本地单用户程序。程序和作品文件保存在自己的电脑上，真实写作会将必要的选题、素材与回答发给配置的模型服务，也会访问搜索服务，可能产生费用。可以直接配置 OpenAI 兼容服务，无需安装网关。

## 安装

需要 Python 3.12、uv，以及满足前端依赖要求的 Node.js（20.19+ 或 22.12+ 的兼容版本；建议使用 22 系列）。在项目根目录执行：

```bash
uv sync --locked
cd web
npm ci
npm run build
cd ..
```

Python 依赖由 `uv.lock` 锁定，前端依赖由 `web/package-lock.json` 锁定。安装依赖需要联网。

## 启动网页

macOS / Linux：

```bash
bash run.sh
```

Windows PowerShell：

```powershell
.\run.ps1
```

浏览器访问 `http://127.0.0.1:8000`。这两个脚本都使用一个前台服务托管构建后的页面，按 Ctrl+C 停止，默认只监听本机。也可直接运行：

```bash
uv run --locked uvicorn server:app --host 127.0.0.1 --port 8000
```

没有 `.env` 或未填写密钥、模型时，网页会显示缺少哪些配置，“开始写作”保持禁用。配置检查只检查必填项和地址格式，不调用模型，不验证额度或模型权限。

## 连接自己的模型

首次配置时，在项目根目录复制样例；已有 `.env` 时直接编辑，不要覆盖：

```bash
cp .env.example .env
```

PowerShell 使用 `Copy-Item .env.example .env`。填写以下项目：

| 配置项 | 填什么 |
|---|---|
| `LLM_BASE_URL` | 服务商提供的 OpenAI 兼容 API 地址，通常包含 `/v1`；直连 OpenAI 可留空 |
| `LLM_API_KEY` | 使用者自己的密钥；也可通过 `OPENAI_API_KEY` 提供 |
| `LLM_MODEL` | 服务商实际支持的模型名称，默认用于所有写作步骤 |
| `AUTHOR_PROFILE` | 可选背景，例如熟悉的语言、希望的讲解深度；留空时使用中性提示 |

保存后重启后台，在页面点击“重新检查”。配置状态接口仅返回是否已填写，不返回密钥、服务地址或作者背景。“配置已填写”不保证密钥有效；真实调用遇到认证、连接、额度或协议问题时会给出对应提示。

研究模型需要支持 OpenAI 兼容的工具调用。`TOKEN_PARAM` 默认 `max_tokens`；若服务要求另一种参数，可改为 `max_completion_tokens`。不同服务的具体兼容性需要实际验证。

当前只适配 OpenAI Chat Completions 兼容协议。使用 DeepSeek 官方 `deepseek-v4-pro` 时，按 [DeepSeek 配置与验收](docs/deepseek.md) 操作。研究员会在后续工具调用中保留服务商返回的 `reasoning_content`，但不会将这个字段作为素材、文章正文或日志输出。

思考模型可设置 `LLM_MIN_OUTPUT_TOKENS`，为各写作步骤设置最低输出预算；留空或 `0` 沿用各步骤默认值。该值不能超过 `CHAT_TOKENS_CAP`（默认 `16000`）。空输出、截断或无效搜索调用会有限重试；用尽后提示失败，编辑则保留作者原回答并提示。应用层默认每次生成最多尝试 3 次；研究员最多进行 4 轮搜索决策，随后请求一次不带工具的收尾生成。一次搜索决策可能包含多个查询。

高级配置可用 `MODEL_SLOOP` 覆盖研究与策划模型，用 `MODEL_GALLEON` 覆盖教学、编辑和终审模型。首版 Web 不要求单独填写未使用的 raft、ark 档位。配置统一从项目根目录的 `.env` 读取；修改后重启后台。

如果日志显示 `超时阶段=connect`，可在 `.env` 设置 `LLM_CONNECT_TIMEOUT_SECONDS=20` 后重启后台，为建立连接预留更多时间。允许范围为 1–120 秒，留空使用 SDK 默认值；只调整建连等待，读取、发送、连接池等待和 SDK 重试次数保持原样。持续连不上时会等得更久，这个设置不能保证修复网络或代理故障。

## 本地作品与项目复盘

| 位置或配置 | 用途 |
|---|---|
| `local_artifacts/blogs/` | 默认保存素材、提纲、问答、草稿及终审意见，Git 已忽略 |
| `LOCAL_ARTIFACTS_DIR` | 可选的个人产物根目录；使用外部路径时需要自行保管和备份 |
| `MAKINGOF_MATERIAL` | 指向自己的素材文件；设置后整个服务进入项目复盘模式 |
| `MAKINGOF_OUT` | 复盘稿路径，默认 `local_artifacts/blogs/draft-makingof.md` |
| `GW_LEDGER` | 可选兼容网关账本路径；不设置时显示“未接入费用记录”，不影响写作 |

未接入账本时不会把未知费用显示为零。已接入但文件不可读、没有该篇记录或记录缺少费用时也会分别说明。页面展示的是已有记录，实际费用以服务商账单为准。

已有续写依靠文件识别已完成的节，尚不保证刷新页面或后台重启后恢复全部对话状态。已经开始写作的提纲不能直接重排，以免新提纲和已存草稿混在一起。未完成的回答、服务重启后的恢复体验仍待后续优化。

## 开发与检查

页面开发时可在两个终端分别运行后台和前端：

```bash
uv run --locked uvicorn server:app --reload --host 127.0.0.1 --port 8000
```

另一个终端进入 `web/` 后运行 `npm run dev -- --host 127.0.0.1`，访问 Vite 显示的本机地址。结束时分别按 Ctrl+C。

完成 Python 和前端依赖安装后，在运行环境执行：

```bash
bash verify.sh
```

该脚本执行写作流程、Web HTTP、思考模型兼容性检查，以及前端代码检查和构建，任一步失败就停止。Python 检查使用测试专用的模拟 SDK，或真实 SDK 配合模拟 HTTP 响应；搜索函数也被替换，不访问真实模型或搜索服务。产品中没有假数据模式。

Windows 开发机仅做代码修改与静态核对；自动检查由 GitHub Actions 执行，真实调用和页面验收由 Mac 使用者完成。测试夹具通过不等于已通过真实 DeepSeek 验收。详见 [Mac 验收步骤](docs/mac-validation.md)、[目录与迁移记录](docs/migration.md) 和 [评测工具说明](docs/evaluation.md)。旧假数据截图已移除，待实际验收后补充合适的界面图片。
